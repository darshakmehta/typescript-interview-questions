To incorporate the **Factory Design Pattern** into the **React + TypeScript** example, we can create a `PaymentProcessorFactory` that dynamically instantiates the appropriate payment processor based on the payment method. This makes the system even more flexible and adheres to the **Open/Closed Principle (OCP)**.

---

### **Step 1: Define the `PaymentProcessor` Interface**

This remains the same as before.

```ts
interface PaymentProcessor {
  processPayment(amount: number): void;
}
```

---

### **Step 2: Implement Specific Processors**

These are the same as before.

```ts
// Credit Card Processor
class CreditCardProcessor implements PaymentProcessor {
  processPayment(amount: number): void {
    console.log(`Processing credit card payment of $${amount}`);
  }
}

// PayPal Processor
class PaypalProcessor implements PaymentProcessor {
  processPayment(amount: number): void {
    console.log(`Processing PayPal payment of $${amount}`);
  }
}

// Bitcoin Processor
class BitcoinProcessor implements PaymentProcessor {
  processPayment(amount: number): void {
    console.log(`Processing Bitcoin payment of $${amount}`);
  }
}
```

---

### **Step 3: Create a Factory**

The `PaymentProcessorFactory` will handle the creation of the appropriate payment processor based on the payment method.

```ts
class PaymentProcessorFactory {
  static createProcessor(method: string): PaymentProcessor {
    switch (method) {
      case 'creditCard':
        return new CreditCardProcessor();
      case 'paypal':
        return new PaypalProcessor();
      case 'bitcoin':
        return new BitcoinProcessor();
      default:
        throw new Error('Invalid payment method');
    }
  }
}
```

---

### **Step 4: Create a React Component**

The `PaymentButton` component will now accept a `paymentMethod` prop instead of a `processor` prop. It will use the factory to create the appropriate processor.

```tsx
import React from 'react';
import { PaymentProcessorFactory } from './PaymentProcessorFactory';

interface PaymentProps {
  paymentMethod: string;
  amount: number;
}

const PaymentButton: React.FC<PaymentProps> = ({ paymentMethod, amount }) => {
  const handlePayment = () => {
    const processor = PaymentProcessorFactory.createProcessor(paymentMethod);
    processor.processPayment(amount);
  };

  return (
    <button onClick={handlePayment}>
      Pay ${amount} with {paymentMethod}
    </button>
  );
};

export default PaymentButton;
```

---

### **Step 5: Use the Component**

Now, you can use the `PaymentButton` component by specifying the payment method as a prop.

```tsx
import React from 'react';
import PaymentButton from './PaymentButton';

const App: React.FC = () => {
  return (
    <div>
      <h1>Payment System</h1>
      <PaymentButton paymentMethod='creditCard' amount={100} />
      <PaymentButton paymentMethod='paypal' amount={50} />
      <PaymentButton paymentMethod='bitcoin' amount={75} />
    </div>
  );
};

export default App;
```

---

### **Step 6: Extending the System**

If you need to add a new payment method (e.g., Apple Pay), you can simply:

1. Create a new class implementing `PaymentProcessor`.
2. Update the `PaymentProcessorFactory` to handle the new method.

```ts
// Apple Pay Processor
class ApplePayProcessor implements PaymentProcessor {
  processPayment(amount: number): void {
    console.log(`Processing Apple Pay payment of $${amount}`);
  }
}

// Updated Factory
class PaymentProcessorFactory {
  static createProcessor(method: string): PaymentProcessor {
    switch (method) {
      case 'creditCard':
        return new CreditCardProcessor();
      case 'paypal':
        return new PaypalProcessor();
      case 'bitcoin':
        return new BitcoinProcessor();
      case 'applePay':
        return new ApplePayProcessor();
      default:
        throw new Error('Invalid payment method');
    }
  }
}
```

Now, you can use the new payment method in your React component:

```tsx
<PaymentButton paymentMethod='applePay' amount={200} />
```

---

### **Key Benefits of Using Factory Pattern**

1. **Separation of Concerns**: The creation logic is centralized in the factory, making the code cleaner and easier to maintain.
2. **Open/Closed Principle**: You can add new payment methods without modifying existing code.
3. **Flexibility**: The React component doesn't need to know about the specific payment processors; it only interacts with the factory.

This approach makes your React + TypeScript application highly scalable and adheres to SOLID principles. 🚀
